# Analyst Prep Kit — тренажёр аналитика данных

Бесплатный интерактивный набор для подготовки к первой работе в аналитике данных. Работает в браузере: сборка, регистрация, Node.js и Docker не требуются.

**Онлайн-версия форка с русификатором:** https://grigoriiboris-glitch.github.io/analyst-prep-kit/ (если включён GitHub Pages). Оригинал на английском: https://michaelnocito.github.io/analyst-prep-kit/  
**Запуск на Windows и Ubuntu:** [RUN_RU.md](RUN_RU.md)

## Новые практические модули

- **Основы аналитики данных:** 8 последовательных уроков с проверочными вопросами и сохранением прогресса.
- **Качество данных:** поиск дубликатов, пропусков, проблем формата и числовых значений; экспорт очищенного файла и исключений.
- **Проекты для портфолио:** три бизнес-кейса с учебными CSV, пошаговыми заданиями, критериями готовности и скачиваемым README.

Каждый модуль работает на HTML/JavaScript без сборки и серверной базы данных.

## Русский язык

На страницах добавлен переключатель «Русский · EN». Подписи из встроенного словаря переводятся локально, другие видимые фрагменты уроков автоматически переводятся онлайн и кешируются в браузере. API-ключ не требуется. Для перевода отправляются видимые текстовые фрагменты страницы. Поля ввода, редакторы и блоки кода исключены; если ответ пользователя показан как обычный текст страницы, он тоже может быть отправлен на перевод. Не вводите конфиденциальные данные. Без интернета часть текста может остаться на английском. Бесплатные внешние службы могут ограничивать частоту запросов. Синтаксис SQL/Python и технический код сохраняются.

Прогресс уроков хранится в localStorage текущего браузера. Необязательная обратная связь в симуляторе может использовать Claude API и собственный API-ключ; для стандартных уроков он не нужен.

Это учебный тренажёр, а не аккредитованная программа и не гарантия трудоустройства. Оригинальный проект создан [Michael Nocito](https://michaelnocito.github.io).
