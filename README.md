# Analyst Prep Kit — тренажёр аналитика данных

Бесплатный интерактивный набор для подготовки к первой работе в аналитике данных. Работает в браузере: сборка, регистрация, Node.js и Docker не требуются.

**Онлайн-версия форка с русификатором:** https://grigoriiboris-glitch.github.io/analyst-prep-kit/ (если включён GitHub Pages). Оригинал на английском: https://michaelnocito.github.io/analyst-prep-kit/  
**Запуск на Windows и Ubuntu:** [RUN_RU.md](RUN_RU.md)

## Новые практические модули

- **Основы аналитики данных:** 8 последовательных уроков с проверочными вопросами и сохранением прогресса.
- **Основы бизнес-анализа:** 9 русскоязычных интерактивных уроков от постановки проблемы до критериев приёмки и управления изменениями. Итоговый кейс позволяет сохранить черновик, проверить его полноту по чек-листу, скопировать документ или экспортировать его в Markdown. Ответы, текущий урок и прогресс сохраняются; модуль подключён к общей синхронизации и кошельку DataCraft.
- **Качество данных:** поиск дубликатов, пропусков, проблем формата и числовых значений; экспорт очищенного файла и исключений.
- **Проекты для портфолио:** три бизнес-кейса с учебными CSV, пошаговыми заданиями, критериями готовности и скачиваемым README.
- **DataCraft:** 2D-мир с картой учебных зданий и раскрывающимися списками уроков. Карта читает прогресс 15 основных курсов и показывает, что пройдено и что осталось. За первые завершения уроков и практических этапов начисляются монеты; их можно потратить на постройку зданий, крафт и игровые действия. Открытие урока повторно не даёт монеты второй раз. Дополнительно доступны контракты, ресурсная экспедиция, 13 сертификационных веток и Project Studio. Монетный кошелёк общий для модулей и хранится в localStorage.

Каждый модуль работает на HTML/JavaScript без сборки и серверной базы данных.

## Рекомендуемый маршрут для новичка

1. [Основы аналитики данных](foundations/) — понять таблицы, метрики и ход работы аналитика.
2. [Основы бизнес-анализа](business-analysis/) — дополнительный путь для тех, кто хочет описывать процессы и требования в IT.
3. [Практикум по качеству данных](data-quality/) — научиться замечать ошибки до расчётов.
3. [SQL](sql/) — получать и объединять данные.
4. [PostgreSQL](postgresql/) — изучать особенности PostgreSQL на выполняемых SQL-примерах.
4. [Excel](excel/) — очищать таблицы, считать показатели и делать сводные отчёты.
5. [Статистика](stats/) — аккуратно интерпретировать результат и сравнивать группы.
6. [Power BI](powerbi/) — собрать модель данных и дашборд.
7. [Три проекта для портфолио](portfolio-projects/) — сделать кейсы по продажам, поддержке и маркетингу.
8. [Подготовка к собеседованию](interview/) и [симулятор аналитика](simulator/) — потренироваться решать рабочие задачи и объяснять решения.
9. Итоговый экзамен, затем углубление в Python и Tableau по требованиям выбранных вакансий.

## Русский язык

Русский — единственный язык интерфейса. Переключателя языка и браузерного автоперевода нет: подписи страниц, кнопок, уроков и сообщений сохранены в готовом HTML/JavaScript. Для открытия и обучения переводчик и интернет не нужны. Названия инструментов (SQL, Excel, Python, Power BI, Tableau), общепринятые аббревиатуры и примеры кода сохраняются там, где перевод мог бы изменить технический смысл.

Проверка `tools/check-static-russian.js` входит в CI и проверяет все HTML-страницы: язык документа, отсутствие старого онлайн-русификатора и переключателя, а также распространённые английские подписи элементов интерфейса. Для обновления статического перевода используется сборка GitHub Actions `Build static Russian version`; при открытии сайта внешние службы перевода не вызываются.

Прогресс уроков хранится в localStorage текущего браузера. Необязательная обратная связь в симуляторе может использовать Claude API и собственный API-ключ; для стандартных уроков он не нужен.

Это учебный тренажёр, а не аккредитованная программа и не гарантия трудоустройства. Оригинальный проект создан [Michael Nocito](https://michaelnocito.github.io).
