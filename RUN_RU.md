# Запуск Analyst Prep Kit на Windows и Ubuntu

Приложение состоит из статических HTML-страниц. Сборка, Node.js, Docker и Python-библиотеки не нужны. Открывайте страницы через локальный HTTP-сервер, а не двойным щелчком по index.html.

## Новые учебные разделы

После запуска открой разделы с корневой страницы или напрямую:

- Основы аналитики: http://127.0.0.1:8000/foundations/
- Качество данных: http://127.0.0.1:8000/data-quality/
- Проекты для портфолио: http://127.0.0.1:8000/portfolio-projects/
- DataCraft — 2D-игра с ресурсами и крафтом: http://127.0.0.1:8000/datacraft/ (карта показывает требования и прогресс каждого основного курса)
- На карте DataCraft нажми на здание, чтобы увидеть уроки, отметки прохождения, предварительные требования и цену постройки. Монеты автоматически начисляются за впервые завершённые уроки; баланс общий с ресурсной мастерской и сохраняется в браузере.

## Онлайн

Откройте русифицированный форк: https://grigoriiboris-glitch.github.io/analyst-prep-kit/ (если GitHub Pages включён). Если страница пока не опубликована, используйте локальный запуск ниже. Оригинал на английском: https://michaelnocito.github.io/analyst-prep-kit/. Автоматический перевод незнакомых фрагментов требует интернета.

## Windows 10/11

### 1. Установите Git и Python

Откройте PowerShell и выполните:

~~~powershell
winget install --id Git.Git -e
winget install --id Python.Python.3.12 -e
~~~

Закройте и снова откройте PowerShell. Если winget недоступен, скачайте установщики: https://git-scm.com/download/win и https://www.python.org/downloads/windows/.

### 2. Скачайте проект

~~~powershell
git clone https://github.com/grigoriiboris-glitch/analyst-prep-kit.git
cd analyst-prep-kit
~~~

Без Git можно нажать **Code → Download ZIP** на странице репозитория, распаковать архив и открыть PowerShell в этой папке.

### 3. Запустите сайт

~~~powershell
py -m http.server 8000 --bind 127.0.0.1
~~~

Оставьте PowerShell открытым. В браузере откройте http://127.0.0.1:8000/ . Чтобы остановить сервер, нажмите **Ctrl+C**.

## Ubuntu Linux

### 1. Установите Git и Python

~~~bash
sudo apt update
sudo apt install -y git python3
~~~

### 2. Скачайте проект

~~~bash
git clone https://github.com/grigoriiboris-glitch/analyst-prep-kit.git
cd analyst-prep-kit
~~~

### 3. Запустите сайт

~~~bash
bash ./start-server.sh
~~~

Скрипт автоматически останавливает предыдущий экземпляр HTTP-сервера этого проекта на выбранном порту и повторно запускает сайт на том же порту. Он не завершает процессы других приложений.

Не закрывайте терминал, пока используете сайт. В браузере откройте http://127.0.0.1:8000/ . Для остановки нажмите **Ctrl+C**.

## Повторный запуск и занятый порт

В Ubuntu запускайте сайт командой `bash ./start-server.sh`. Если предыдущий сервер этого проекта всё ещё работает на порту 8000, скрипт остановит его и запустит новый экземпляр на `http://127.0.0.1:8000/`.

Если порт занят другим приложением, скрипт не будет завершать его автоматически. Узнать процесс можно командой `sudo ss -ltnp 'sport = :8000'`. Для разового запуска на другом порту используйте `PORT=8080 bash ./start-server.sh` и откройте http://127.0.0.1:8080/.

В Windows при занятом порте можно запустить сервер на 8080: `py -m http.server 8080 --bind 127.0.0.1`, затем открыть http://127.0.0.1:8080/.

## Переключение языка и заметки

Переключатель «Русский · EN» находится вверху справа. Выбор сохраняется в браузере. Перевод незнакомых видимых фрагментов выполняется онлайн и кешируется. SQL, Python, блоки кода, редакторы и поля ввода не переводятся. Если ответ пользователя отображается как обычный текст страницы, он может попасть в запрос перевода; не вводите конфиденциальные данные. Бесплатные службы перевода могут ограничивать частоту запросов.

- Не публикуйте локальный сервер в интернет: он слушает только 127.0.0.1.
- Не закрывайте PowerShell или терминал до завершения работы.
- Прогресс хранится в localStorage. Очистка данных сайта может его удалить.
- Для стандартных уроков ключи API не нужны. Проверка ответов через Claude в симуляторе необязательна и может быть платной.
- Если GitHub Pages ещё не включён, откройте **Settings → Pages**, выберите ветку main и папку /(root).
