Практика как на работе

Три проекта для портфолио аналитика

Выбери задачу, скачай CSV, сделай расчёты в Excel или SQL, подготовь дашборд и сформулируй рекомендации. Каждый проект начинается с бизнес-вопроса и заканчивается артефактами, которые можно показать работодателю.

Данные синтетические, но устроены как рабочие выгрузки: сотни записей, повторяющиеся сущности, временной период и несколько намеренных ошибок качества. Это учебные кейсы, а не готовые результаты для резюме: расчёты, запросы, дашборд и выводы нужно сделать самостоятельно.

        Учебный набор данных

        Файлы формируются в браузере; сервер не нужен.

        В CSV специально есть несколько проблем качества. Сначала найди и задокументируй их, затем рассчитай метрики. Для портфолио сохрани итоговые SQL, файл Excel или Power BI, скриншот дашборда и краткое резюме для руководителя.

        Проверка готовности

        Отмечай выполненные пункты. Прогресс сохраняется отдельно для каждого проекта.

        Твои выводы

        Текст сохраняется локально в текущем браузере и попадёт в шаблон README при скачивании.

        Оцени качество результата

        • Могу повторить расчёт.
        • Проверил пропуски и дубликаты.
        • Не путаю корреляцию с причинностью.
        • Мои рекомендации связаны с данными.

        Три правильно завершённых кейса обычно полезнее десяти незаконченных. Для каждого сохрани исходный и очищенный CSV, словарь данных, воспроизводимые расчёты, дашборд, README с реальными результатами, ограничения и следующий бизнес-шаг. Не публикуй шаблон с незаполненными выводами как готовый проект. Чек-лист и черновик выводов сохраняются в локальное хранилище этого браузера.
