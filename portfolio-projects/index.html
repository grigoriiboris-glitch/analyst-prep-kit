Практика как на работе

Три проекта для портфолио аналитика

Выбери задачу, скачай CSV, сделай расчёты в Excel или SQL, подготовь дашборд и сформулируй рекомендации. Каждый проект начинается с бизнес-вопроса и заканчивается артефактами, которые можно показать работодателю.

Данные вымышлены. В каждом проекте есть техническое задание, подсказки, критерии готовности и генератор шаблона README для GitHub.
