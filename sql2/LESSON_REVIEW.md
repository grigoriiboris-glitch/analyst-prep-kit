## Общий чек-лист

Все 24 урока прошли проверку по единому чек-листу:

- [x] Тема соответствует тому, что ученик собирает в запросе.
- [x] В уроке одна главная учебная цель; остальные конструкции уже встречались ранее.
- [x] Перед заданием есть объяснение и отдельный форматированный пример SQL.
- [x] Подсказка помогает рассуждать, но не содержит готового запроса.
- [x] Поле редактора начинается пустым; целевой запрос ученик собирает сам из блоков.
- [x] Есть блоки-отвлекающие варианты, которые не нужно выбирать.
- [x] Указаны ожидаемые столбцы, размер результата и контрольные строки/значения.
- [x] Есть SQL-разбор с объяснением, почему запрос работает.
- [x] Есть типичная ошибка новичка.
- [x] Есть короткий вопрос для самопроверки.
- [x] В учебном тексте нет инструкций для ИИ и служебных заметок.

## Интерактивное поведение

Каждое из 24 заданий теперь использует один и тот же сценарий:

1. Ученик видит перемешанные SQL-блоки.
2. Нажимает блоки в нужной последовательности, собирая запрос.
3. Лишние варианты можно не выбирать; ошибочный выбранный блок можно вернуть обратно нажатием на него.
4. Собранный запрос отображается в редакторе только для чтения.
5. Кнопка выполнения запускает запрос в локальной SQLite-песочнице и сравнивает результат с эталонным запросом урока.
6. Прогресс и награда начисляются только после совпадения результата.

Кнопка сброса очищает сборку. Переход между уроками, подсказка, разбор решения, копирование контекста для ИИ и просмотр результата сохранены.

## Прогресс после обновления содержания

Так как задания заменены, для SQL 2 создан новый ключ состояния `sql2kit-v2` и отдельный идентификатор облачной синхронизации `sql2-v2`. Старое состояние `sql2kit-v1` не используется для новых заданий: уроки начнутся с нуля, а ранее сохранённый прогресс не будет ошибочно показывать новые упражнения выполненными. Остальные курсы не затрагиваются.

## Техническая проверка

Добавлена/обновлена автоматическая проверка, которая исполняет все 24 решения на том же наборе демонстрационных данных SQLite, что загружается в браузерный практикум. Проверяются:

- успешное выполнение каждого SQL-запроса;
- имена и порядок столбцов;
- количество и порядок строк;
- контрольные значения по товарам, клиентам, категориям, платежам и оконным расчётам.

Проверка запускается в GitHub Actions `Validate learning modules`. Дополнительно проверяются синтаксис JavaScript, интерактивные блоки и отдельный ключ прогресса SQL 2.
