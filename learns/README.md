# Материалы учебных модулей

Каталог `learns` — полный текстовый архив учебных программ Analyst Prep Kit. В каждом из 16 модулей сохранены все материалы, которые реально используются в приложении: полные уроки, интерактивные практикумы или проекты. Исходные редакторские документы `_edited` не заменяются и остаются в начале соответствующих файлов.

## Синхронизация с приложением

В приложении есть два связанных слоя:

1. Нативные уроки курса в HTML/JavaScript — карточки, объяснения, примеры, задания, вопросы, ответы, визуализации и проверочная логика.
2. Редакторские материалы `_edited` из Google Drive — они встроены в 15 соответствующих HTML-страниц в `template#edited-source-data` и автоматически отображаются компонентом `assets/edited-lesson-content.js`. Для статических и динамических курсов блоки показываются рядом с соответствующим уроком или в библиотеке материалов.

Файлы Markdown сохраняют полное содержимое нативных уроков из первого слоя. Для JS-курсов перенесены полные объекты уроков, для HTML-курсов — исходная разметка и читаемый текст, для практикума качества данных и портфолио — также полные исходные страницы с логикой и данными. Это архивная синхронизация; карточки в интерфейсе повторно не создаются, существующий прогресс и интерактивные задания не заменяются.

## Сохранение технического синтаксиса

SQL, PostgreSQL, Python, DAX, Tableau expressions, формулы, имена функций, идентификаторы полей, значения данных и примеры команд сохраняются в исходном синтаксисе. Переводится объясняющий текст, а не язык инструмента. Интерактивные задания, варианты ответов, правильные решения и подсказки архивируются вместе с текстом урока.

## Автоматические проверки

- `tests/learns-course-archive.test.js` проверяет шесть ранее расширенных курсов, точные названия и порядок уроков, 15 встроенных исходников `_edited` и счётчик SQL.
- `tests/learns-all-course-content.test.js` дополнительно сверяет все оставшиеся 10 модулей непосредственно с HTML/JS-источниками: точное число, порядок и заголовки, а для новых архивов — наличие полного исходного объекта или разметки каждого урока.
- Оба теста выполняются в GitHub Actions `Validate learning modules`.

Проверки предназначены для того, чтобы изменение программы в приложении без синхронного обновления архива `learns` приводило к ошибке CI.
