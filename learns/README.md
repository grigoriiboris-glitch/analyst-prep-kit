Это редакторские материалы для сверки с интерактивными страницами; обновление Markdown само по себе не меняет исполняемую разметку уроков в `index.html` или внешних JS-файлах.

## Полнота учебных программ в архиве

В Markdown-файлах сохранены два слоя: исходные редакторские материалы `_edited` (они не перезаписываются) и полные тексты уроков, которые уже используются интерактивными курсами. Для модулей, где редакторские документы покрывали только часть программы, добавлен отдельный раздел «Полная программа уроков приложения».

Числа относятся к текущей учебной программе приложения. Для Excel, Power BI, Tableau, статистики, прогнозирования и PostgreSQL полные уроки добавлены в соответствующие Markdown-файлы из рабочих массивов приложения. Остальные модули уже имели соответствующее число материалов в редакторских конспектах или практических сценариях. Проверка `tests/learns-course-archive.test.js` автоматически сверяет количество и точные названия архивных уроков с источниками приложения.

Технический синтаксис, запросы SQL, формулы, DAX и Python-код при переносе сохранены как в учебных страницах.
