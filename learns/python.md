Урок 4. Операторы и логические выражения
Сравнение значений возвращает булево значение (True/False). Операторы: == (равенство), != (неравенство), >, <, >=, <=. Логические операторы: and, or, not.
Урок 5. Списки (Lists) и базовые операции
Список (list) — упорядоченная изменяемая коллекция элементов произвольных типов.
\* Создание: items = [10, 20, 30]
\* Добавление: items.append(40)
\* Удаление: items.pop() или items.remove(val)
Урок 6. Срезы (Slicing) списков и строк
Срез позволяет извлекать подмножество элементов. Синтаксис: sequence[start:stop:step].
\* start — начальный индекс (включительно)
\* stop — конечный индекс (не включительно)
\* step — шаг выборки
data = [0, 10, 20, 30, 40, 50, 60]
print(data[1:4]) # [10, 20, 30]
print(data[:3]) # [0, 10, 20] (первые три)
print(data[-2:]) # [50, 60] (последние два)
print(data[::2]) # [0, 20, 40, 60] (каждый второй)
Урок 7. Словари (Dictionaries)
Словарь (dict) — неупорядоченная (начиная с Python 3.7 — сохраняющая порядок вставки) структура данных типа «ключ-значение». Ключи должны быть неизменяемыми типом (строка, число, кортеж).customer = {"id": 101, "name": "Анна", "orders": 5}
print(customer.get("name")) # 'Анна'

\* Множество (set) — неупорядоченная коллекция уникальных элементов (unique\_ids = {101, 102, 103}).
