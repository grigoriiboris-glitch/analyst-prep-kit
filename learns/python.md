## Урок 1. Что такое код (значения, переменные, сверху вниз)

**Раздел:** Модуль 0: Прежде чем писать код

**Объяснение:**
  **is:**
    Значение — это часть данных. Переменная — это имя, которое вы присваиваете этому значению, и Python читает ваши инструкции сверху вниз, по одной строке за раз.

  **use:**
    Вы называете вещи, прежде чем использовать их. Каждая строка, которую вы пишете, предполагает, что строка над ней уже запущена.

  **like:**
    Следуя рецепту. Вскипятите воду, прежде чем заливать ею чай, иначе вы ничего не льете.

**Рабочая ситуация:**
  Вы использовали Excel и SQL — инструменты с меню и интерфейсами, основанными на щелчках мыши. С Python все по-другому: вы пишете инструкции в виде обычного текста, а компьютер выполняет их построчно, сверху вниз. Прежде чем написать одну операцию с данными, вам понадобится эта мысленная модель: значение — это часть данных, переменная — это имя, которое вы даете значению, а Python читает ваш код от первой строки до последней.

**Теория:**
  Значением является любой фрагмент данных: число 150, строка «Запад», логическое значение «Истина». Переменная — это метка, которую вы прикрепляете к значению — напишите revenue = 150 а Python хранит 150 под названием «доход». С этого момента, где бы вы ни писали revenue , Python использует 150. Важнейшее свойство: Python выполняет ваш код сверху вниз, по одной строке за раз. Порядок имеет значение.

**Разбор и примеры:**
    **formula:**
      
```
доход = 150
```

    **say:**
      Сохраните значение 150 в переменной с именем доход.

    **lines:**
      - **Выручка:** имя переменной — вы выбираете его (без пробелов и начальных цифр)
      - **=:** присваивание — сохраняет значение правой стороны в имя левой стороны
      - **150:** целое значение

    **formula:**
      
```
регион = 'Запад'
```

    **say:**
      Сохраните строку «Запад» в переменной с именем Область.

    **lines:**
      - **Регион:** имя переменной
      - **«Запад»:** строковое значение — текст, заключенный в кавычки (одинарные или двойные)
      - **Python читает сверху вниз:** если вы записываете доход в строке ДО того, как определите его, вы получите ИмяОшибка

**Важно запомнить:**
  Python чувствителен к регистру: «Доход» и «Доход» — это две разные переменные. И отступы не являются обязательными — Python использует пробелы для понимания структуры. Неправильный отступ вызывает ошибку Индентатионеррор, которая полностью останавливает ваш скрипт.

**Визуальное объяснение:**

  **caption:**
    Назначаются две переменные, а затем печатаются. Python выполнил эти три строки по порядку. Строки комментариев (начинающиеся с #) пропускаются.

  - Печатает никто вместо числа
  - Печатает 0, значение по умолчанию.

## Урок 2. Типы данных и ловушка «текст против числа»

**Раздел:** Модуль 0: Прежде чем писать код

**Объяснение:**
  **is:**
    Python сортирует каждое значение по типу — целое число, десятичное число, текст или истинное/ложное — и тип решает, что вам разрешено с ним делать.

  **use:**
    Прежде чем заняться арифметикой, проверьте, что у вас есть. Цифра, полученная в виде текста, не суммируется, а загруженный файл полон ими.

  **like:**
    Две монеты, которые выглядят одинаково, но одна — иностранная валюта. Машина берет одну и выплевывает другую обратно.

**Рабочая ситуация:**
  Вы можете назвать значение. Но Python, как и Excel и SQL, не обрабатывает все значения одинаково. Число 150 и строка «150» выглядят почти одинаково и ведут себя совершенно по-разному. Разделите строку на число, и Python выдаст ошибку ТипОшибка. Зная типы, с которыми вы работаете, вы узнаете, какие операции разрешены.

**Теория:**
  В Python есть четыре типа, с которыми вы постоянно будете сталкиваться при работе с данными: int (целые числа — для счетчиков и идентификаторов), float (десятичные числа — для цен и тарифов), str (строки — текст: имена, коды, категории) и bool (Верно или Неверно — для флагов и фильтров). Ловушка: CSV-файл, в котором «150» хранится в виде текста, а 150 — в виде числа, на экране выглядит одинаково, но в коде ведет себя по-разному.

**Разбор и примеры:**
    **formula:**
      
```
тип(150) # → целое
```

    **say:**
      Спросите Python, что такое тип 150. Это целое число.

    **lines:**
      - **тип(:** Тип() (спросите, что это за значение) — встроенная функция, которую вы вызываете с любым значением
      - **150:** проверяемое значение — целое число, без кавычек и десятичной дроби
      - **# → целое:** комментарий показывает ответ: интервал, целочисленный тип Python
      - **четыре типа:** int (whole number), float (decimal), str (text in quotes), bool (True/False)

    **formula:**
      
```
int('150') # → 150
```

    **say:**
      Преобразуйте строку «150» в целое число 150.

    **lines:**
      - **интервал(:** интервал() (преобразование в целое число) — принимает значение и возвращает целое число
      - **'150':** строка — кавычки делают ее текстовой, даже если она выглядит числовой
      - **# → 150:** результат: действительное число 150, которое теперь можно использовать в математике.
      - **float(x) / str(x):** родственные преобразователи — в десятичное число, в текст; неконвертируемый текст вызывает ValueError

**Важно запомнить:**
  Когда вы загружаете CSV-файл, pandas иногда считывает числовые столбцы как строки, особенно идентификаторы и коды. Прежде чем начать, проверьте типы вашего DataFrame с помощью df.dtypes. Сумма столбца до 0 или выдача TypeError почти всегда является несоответствием типа.

## Урок 3. Что такое библиотека и почему pandas (импорт)

**Раздел:** Модуль 0: Прежде чем писать код

**Объяснение:**
  **is:**
    Библиотека — это набор инструментов, уже написанных кем-то другим. Одна строка загружает его в вашу работу и дает ему короткое имя.

  **use:**
    Оно идет на самом верху, над всем, что в нем нуждается. Установка происходит один раз на вашем компьютере; загрузка происходит в каждом файле, который вы пишете.

  **like:**
    Прежде чем начать, снимите с полки ящик для инструментов. Ничто в нем не работает, пока оно находится в шкафу.

**Рабочая ситуация:**
  Вы знаете основные типы Питон. Но встроенные инструменты Python ничего не знают о Кадры данных, CSV-файлах или статистических сводках. Библиотека — это набор инструментов, написанных кем-то другим, которые вы активируете с помощью импорта. Pandas — это библиотека, которая превращает Python в инструмент анализа данных — без нее вы бы потратили недели на то, чтобы заново изобрести то, что pandas делают «из коробки».

**Теория:**
  Python поставляется с небольшим набором встроенных инструментов. Библиотеки расширяют его. import pandas as pd загружает библиотеку pandas и присваивает ей псевдоним «ПД» — поэтому вы вводите pd.read_csv() вместо pandas.read_csv() . Каждый аналитик данных также использует NumPy (математика с массивами), Matplotlib (диаграммы), а часто Сиборн (более красивые графики). Вы устанавливаете библиотеки один раз ( pip install pandas ); вы импортируете их в верхней части каждого скрипта.

**Разбор и примеры:**
    **formula:**
      
```

```

    **say:**
      Загрузите библиотеку pandas и назовите ее «ПД» в этом скрипте.

    **lines:**

      - **pandas:** имя библиотеки — устанавливается один раз с помощью пункт установить pandas
      - **как ПД:** как (дайте ему псевдоним) — каждый последующий вызов становится pd.something вместо pandas.что-то
      - **pd.read_csv('file.csv'):** первый пд. вызов, который вы сделаете — прочитайте CSV-файл в DataFrame

**Важно запомнить:**
  Оператор импорта располагается в самом верху вашего скрипта — перед любым кодом, использующим библиотеку. Если вы напишете «df = pd.read_csv(...)» перед «import pandas as pd», вы получите Ошибка имени. Соглашение: сначала весь импорт, затем ваш код.

## Урок 4. Что на самом деле представляет собой DataFrame (строки, столбцы, индекс, зернистость)

**Раздел:** Модуль 0: Прежде чем писать код

**Объяснение:**
  **is:**
    DataFrame — это двумерная сетка записей и полей с отдельной нумерацией по той стороне, которая не является частью ваших данных.

  **use:**
    Прежде чем что-либо анализировать, спросите, что на самом деле представляет собой та или иная запись. Получите это неправильно, и каждая сумма после него тоже неверна.

  **like:**
    План рассадки. Прежде чем что-либо считать, вы решаете, представляет ли каждая линия одного человека или целую семью.

**Рабочая ситуация:**
  Вы можете импортировать pandas. Теперь ключевая концепция, прежде чем приступить к анализу: DataFrame — это двумерная таблица, точно такая же, как электронная таблица, с помеченными столбцами (полями) и индексом строки. И, как и у каждой таблицы в SQL и Excel, у нее есть уровень детализации: что представляет собой одна строка. В данных о продажах кофе одна строка = одна продажа. Если вы неправильно определите уровень детализации, то каждое последующее группирование и слияние будет молча вводить вас в заблуждение.

**Теория:**
  pandas DataFrame — это двумерная таблица: строки — это записи, столбцы — это поля, а специальный целочисленный индекс нумерует строки (0, 1, 2…). Индекс — это не столбец, а отдельная метка. Три вызова, которые вы делаете для каждого нового DataFrame: df.head() чтобы увидеть первые ряды, df.dtypes чтобы увидеть тип каждого столбца, df.shape видеть (строки, столбцы). А затем спросите: что представляет собой одна строка?

**Разбор и примеры:**
    **formula:**
      
```
df.shape
```

    **say:**
      Сколько строк и столбцов имеет этот DataFrame?

    **lines:**
      - **дф:** загруженный вами DataFrame — сама таблица
      - **.shape:** shape (report the size) — a tuple of (rows, columns), e.g. (500, 4)
      - **df.head() / df.dtypes:** сопутствующие вызовы с правом первого просмотра — просмотрите первые 5 строк и перечислите тип каждого столбца, чтобы уловить числа, маскирующиеся под текст.

    **formula:**
      
```
df['Region'].value_counts()
```

    **say:**
      Подсчитайте, сколько строк принадлежит каждому уникальному значению региона.

    **lines:**
      - **df['Region']:** `df['col']` выбирает один столбец и возвращает объект Ряд — набор значений с одной меткой столбца.
      - **.value_counts():** value_counts (подсчет каждого уникального значения) — один счетчик на регион, наиболее часто встречающийся в начале
      - **одна строка = одна продажа:** уровень детализации этого DataFrame — укажите его перед анализом

**Важно запомнить:**
  Индекс не является вашими данными. Не помещайте столбец «номер строки» в свой DataFrame — это то, что индекс уже делает. **Раздел:** Глава 1: Основы Python

**Объяснение:**

## Урок 7. Функции и циклы

**Раздел:** Глава 1: Основы Python

**Объяснение:**
  **is:**

  **use:**
    Напишите шаг один раз, а затем примените его ко всему. И помните, что показать результат на экране — это не то же самое, что вернуть его обратно.

  **like:**

**Рабочая ситуация:**
  Вы можете создавать коллекции — списки и словари. Но повторение одной и той же операции для каждого элемента вручную не масштабируется. Логика пакета функций, которую вы можете вызывать по имени — напишите ее один раз и используйте где угодно. Цикл применяет его к каждому элементу коллекции. Вместе они превращают «сделай это для каждой строки» из утомительного в одну строку.

**Теория:**

Функции позволяют давать блокам кода имена и использовать их повторно; циклы позволяют выполнять действие над каждым элементом коллекции. Вместе они составляют основу большинства скриптов для анализа данных.

DataFrame — это таблица в Python — строки и столбцы, как в электронной таблице. pandas — это библиотека, которая их создает и управляет. Это наиболее часто используемый инструмент в стеке Python для аналитиков данных. Новое ключевое слово, которое вы увидите: import — так Python загружает внешнюю библиотеку в ваш скрипт. ## Урок 10. Фильтрация строк

**Раздел:** Блок 2: pandas

**Объяснение:**
  **is:**
    Вы пишете тест, pandas проверяет его по каждой записи, и возвращаются только те, которые прошли успешно.

  **use:**
    Так широкий запрос становится конкретным. Почти каждый вопрос, который вам задают, начинается с сужения до подмножества.

  **like:**
    Сито над раковиной. Вы опрокидываете всю кастрюлю, и остается только то, к чему вы стремились.

**Рабочая ситуация:**
  Вы уже знаете размер и типы данных DataFrame. Руководитель просит: «Покажи только заказы из региона Запад». В pandas фильтрация выполняется булевой маской: df[df['Region'] == 'West'] . Строки, для которых условие True, остаются; строки с False исключаются. Идея та же, что у WHERE в SQL, но синтаксис другой.

**Теория:**
  Фильтрация похожа на фильтр для кофе: вы пропускаете только те ряды, которые хотите, и оставляете гущу позади. Фильтрация — это логическое индексирование: вы создаете маску «Истина/Ложь», а затем используете ее, чтобы сохранять только те строки, которые вам нужны. Это эквивалент предложения WHERE в pandas.

**Разбор и примеры:**
    **formula:**
      
```
df[df['region'] == 'West']
```

    **say:**
      Дайте мне строки дф, где регион равен «Запад».

    **lines:**
      - **df['region'] == 'West':** сравнивать каждую строку — Верно, если регион — Запад, в противном случае — Неверно
      - **df[...]:** передать маску — сохранять только строки Верно

    **formula:**
      
```
df[(df['revenue'] > 100) & (df['category'] == 'Hot')]
```

    **say:**
      Назовите мне строки, в которых доход превышает 100 И категория равна «Горячие» — оба условия должны быть истинными.

    **lines:**
      - **df['revenue'] > 100:** маска 1: доход выше 100
      - **df['category'] == 'Hot':** маска 2: категория «горячая»
      - **&:** И — оба условия должны быть истинными
      - **( ):** круглые скобки необходимы вокруг каждого условия при объединении

    **formula:**
      
```
df[df['region'].isin(['West', 'East'])]
```

    **say:**
      Назовите мне строки, где регион — «Запад» или «Восток».

    **lines:**
      - **isin(['West', 'East']):** Верно для строк, где регион находится в данном списке.

**Важно запомнить:**
  Всегда заключайте каждое условие в круглые скобки при использовании & (и) или | (или). Без них приоритет операторов Python молча выдаст неправильные результаты.

## Урок 11. Сортировка и выбор

**Раздел:** Блок 2: pandas

**Объяснение:**
  **is:**
    Упорядочите записи по некоторому значению, затем удалите те, что сверху.

  **use:**
    Большинство вопросов типа «покажи мне самое важное» заключаются именно в этом. Порядок также определяет, что читатель увидит первым, а это половина понимания.

  **like:**
    Таблица лидеров. Выстройте всех в ряд по счету, затем зачитайте первые пять.

**Рабочая ситуация:**
  Вы можете фильтровать строки. Теперь вашему менеджеру нужны сначала самые верхние элементы: «Сортировать по убыванию дохода и показывать мне только регион и доход». сортировка_значений() переупорядочивает строки; выбор столбца формирует результат. Результат каждого анализа должен быть читаемым, а не просто правильным.

**Теория:**
  Сортировка и «Топ Н» — это спортивная таблица лидеров: выстройте всех по очкам, а затем выберите лидеров. Как только вы научитесь фильтровать, вам нужно будет сортировать, ранжировать и извлекать важные строки. Эти три метода охватывают 80% вопросов типа «покажи мне первые N».

**Разбор и примеры:**
    **formula:**
      
```

```

    **say:**
      Отсортируйте дф по столбцу дохода, начиная с наибольших значений.

    **lines:**
      - **sort_values('revenue'):** отсортировать строки по столбцу дохода
      - **по возрастанию = Ложь:** сначала наибольшая (в порядке убывания)

    **formula:**
      
```
df.nlargest(5, 'revenue')
```

    **say:**
      Назовите мне 5 строк с наибольшим доходом — ярлык для сортировки плюс заголовок.

    **lines:**
      - **nlargest(5, 'revenue'):** return the 5 rows with the highest revenue — shortcut for sort + head

    **formula:**
      
```
df['region'].value_counts()
```

    **say:**
      Подсчитайте, сколько раз появляется каждый регион, отсортированный от большего к меньшему.

    **lines:**
      - **value_counts():** подсчитывать уникальные значения в столбце, отсортированные по частоте — отлично подходит для быстрой разбивки

**Важно запомнить:**
  сортировка_значений() передает вам отсортированную фотокопию — оригинальная стопка на вашем столе нетронута. Если вы хотите сохранить отсортированный порядок, назначьте его обратно: df = df.sort_values('revenue', возрастающий=False). Или используйте на месте=Истинный.

**Теория:**
  группировка — это объединение распродажи выпечки по принципу «разделить-применить»: разделите печенье по типам, подсчитайте каждый вид, а затем объедините в одну аккуратную сводку. группировка — самый важный навык работы с pandas для аналитика данных. ## Урок 15. Очистка струн

## Урок 17. Глубокая копия против поверхностной копии

**Раздел:** Блок 3: Очистка данных

**Объяснение:**
  **is:**
    Задание не копируется. Два имени могут указывать на одну вещь, поэтому изменение любого имени меняет его для обоих.

  **use:**
    Прежде чем экспериментировать с данными, которые вам еще нужны, сделайте настоящую копию. В этом разница между попыткой чего-то и разрушением оригинала.

  **like:**
    Два человека с ключами от одной квартиры. Это не две квартиры — что бы ни двигала одна из них, другая находит движение.

**Рабочая ситуация:**
  Вы очищаете DataFrame. Вы пишете df2 = дф, изменяете df2 и обнаруживаете, что дф тоже изменился. Это связано с тем, что присваивание не копируется — оба имени указывают на один и тот же объект. В Python есть два вида копирования: поверхностное (новый контейнер, общие внутренние данные) и глубокое (полностью независимый клон). В pandas это становится df.copy() — единственный раз, когда вам нужно вызвать метод, чтобы получить реальную копию.

**Теория:**
  Неполная копия создает новый объект, но использует общие внутренние данные — изменение вложенного значения в копии также изменяет оригинал. Глубокая копия клонирует все рекурсивно — копия полностью независима. В pandas df2 = дф вообще не является копией. df.copy() по умолчанию является глубокой копией.

**Разбор и примеры:**
    **formula:**
      
```
импортировать копию
оригинал = [[1, 2], [3, 4]]
мелкий = copy.copy(оригинал)
глубокий = copy.deepcopy(оригинал)
мелкий[0][0] = 99
# original[0][0] теперь тоже 99 — у них общие внутренние данные!
```

    **say:**
      Неглубокая копия разделяет внутренние списки. Изменение вложенного элемента в поверхностной копии также приводит к изменению оригинала. Глубокая копия полностью независима.

    **lines:**
      - **copy.copy():** неглубокая копия — новый внешний контейнер, общие внутренние объекты
      - **copy.deepcopy():** глубокая копия — полностью независимый клон на каждом уровне
      - **shallow[0][0] = 99:** изменяет общий внутренний список — исходный также изменяется
      - **deep[0][0] = 99:** изменяет только глубокую копию — оригинал остается нетронутым

    **formula:**
      
```
# pandas — версия, которая важна для работы DA
df2 = df # НЕ копия — тот же объект
df2 = df.copy() # глубокое копирование по умолчанию
df2 = df.copy(deep=False) # неглубокая копия (редко)
```

    **say:**
      В pandas df2 = дф дает вам псевдоним, а не копию. df.copy() предоставляет вам полностью независимый DataFrame.

    **lines:**
      - **df2 = df:** присваивание — оба имени указывают на один и тот же объект в памяти
      - **df.copy():** создает независимый DataFrame (по умолчанию глубокий=Верно)
      - **df.copy(deep=False):** неглубокая копия — индекс/столбцы копируются, базовые данные являются общими

**Важно запомнить:**
  Практическое правило DA: всякий раз, когда вы хотите преобразовать подмножество, не затрагивая оригинал, используйте df.copy(). Это также исправление для НастройкаСкопировать предупреждение — это предупреждение появляется, когда pandas обнаруживает, что вы изменяете то, что может быть представлением исходного DataFrame.

## Урок 18. Декораторы

**Раздел:** Блок 3: Очистка данных

**Объяснение:**
  **is:**
    Строка @ над определением передает это определение другой части работы, которая оборачивает вокруг него дополнительное поведение и возвращает завернутую версию.

  **use:**
    Вы прочитаете их гораздо больше, чем напишите — о веб-маршрутизации, тестовых приспособлениях, кэшировании. Распознавание шаблона делает незнакомую работу читабельной.

  **like:**
    Подарочная упаковка. То, что внутри, неизменно; с чем каждый обращается в первую очередь, так это с бумагой, которую вы вокруг него кладете.

**Рабочая ситуация:**
  Вы видите @staticmethod, @property или @app.Маршрут('/') в базе кода и задаетесь вопросом, что делает символ @. Это декораторы — способ Python обернуть функцию дополнительным поведением без редактирования ее тела. Они появляются повсюду: маршрутизация Колба, кэширование pandas, приспособления pytest. Как только вы поймете шаблон, все эти @-строки станут читабельными.

**Теория:**
  Декоратор — это функция, которая принимает на вход другую функцию, добавляет к ней поведение и возвращает измененную версию. Синтаксис @decorator является сокращением функция = декоратор(функция). Вы будете использовать встроенные декораторы гораздо чаще, чем писать свои собственные, но понимание того, как они работают, сделает вас гораздо более свободным читателем Питон.

**Разбор и примеры:**
    **formula:**
      
```
def log_calls(func):
    def wrapper(*args, **kwargs):
        print(f"Calling {func.__name__}...")
        result = func(*args, **kwargs)
        print("Done.")
        return result
    return wrapper

@log_calls
def clean_data(df):
    return df.dropna()
```

    **say:**
      Определите декоратор, который печатает сообщение до и после любой функции, которую оно оборачивает. Примените его с помощью @log_calls над чистые_данные.

    **lines:**
      - **защита log_calls (функция)::** функция декоратора — принимает функцию в качестве аргумента
      - **определеннообертка(*аргументы, **кварги)::** завернутая версия — принимает любые аргументы, которые принимает оригинал
      - **func(*args, **kwargs):** вызывает исходную функцию внутри оболочки
      - **return wrapper:** возвращает расширенную версию функция для ее замены
      - **@log_calls:** сокращение для: чистые_данные = log_calls(чистые_данные)

    **formula:**
      
```
# Распространенные встроенные декораторы
@staticmethod # метод не требует self
@property # метод доступа, подобный атрибуту
@functools.lru_cache() # кэшируем результаты дорогостоящих вызовов
```

    **say:**
      Вы постоянно будете сталкиваться с тремя декораторами — @staticmethod для служебных методов, @property для вычисляемых атрибутов и @lru_cache для мемоизации.

**Объяснение:**
  **is:**

## Урок 31. Постройте P&L на основе бухгалтерской книги

**Раздел:** Глава 6: Финансовый анализ

**Кратко:**
  сгруппируйте по строке оператора, суммируйте, затем каскадируйте промежуточные итоги.

**Объяснение:**
  **is:**
    Суммируйте каждую строку отчета, а затем вычитайте в сторону уменьшения: продажи за вычетом себестоимости товаров дают валовую прибыль, за вычетом накладных расходов дают операционный доход.

  **use:**
    Это превращает необработанный финансовый экспорт в отчет, который на самом деле читают все, и каскад показывает, какой слой съел деньги.

  **like:**
    Ваша расчетная ведомость. Одна большая цифра вверху, каждый вывод на отдельной строке, а тот, что имеет значение, находится внизу.

**Рабочая ситуация:**
  DataFrame реестра содержит тысячи транзакций, каждая из которых помечена строкой отчета — доход, себестоимость, эксплуатационные расходы. Финансовому отделу нужен отчет о прибылях и убытках: выручка, затем стоимость товаров вычитается из валовой прибыли, затем операционные расходы вычитаются из операционного дохода. В pandas это одна группировка по сумме для суммирования каждой строки, за которой следует простое вычитание промежуточных итогов. Вот как аналитик превращает сырьевой экспорт в отчет о прибылях и убытках, который все читают.

**Разбор и примеры:**
    **formula:**
      
```
pnl = df.groupby('line')['amount'].sum()

доход = pnl['Доход']
валовая_профит = выручка - pnl['COGS']
операционная = валовая_прибыль - pnl['Опекс']
print(выручка, валовая_прибыль, операционная)
```

    **say:**
      Сгруппируйте книгу по строкам отчета и просуммируйте суммы, чтобы получить общую сумму по каждой строке, затем вычтите себестоимость товаров из выручки для валовой прибыли и операционные расходы из суммы операционного дохода.

    **lines:**

      - **pnl['Revenue'] - pnl['COGS']:** валовая прибыль: то, что остается после прямой себестоимости продукции

      - **доступ на основе меток:** группировка возвращает серию, индексированную по строкам — читайте каждую строку по имени, а не по позиции

**Важно запомнить:**
  Отчёт о прибылях и убытках состоит из последовательных итогов: выручка − COGS = валовая прибыль, − Операционные расходы = операционная прибыль, − проценты и налоги = чистая прибыль. Каждый уровень отвечает на свой вопрос о бизнесе; группировка и сумма помогают перейти от плоской таблицы операций к такому представлению.

## Урок 32. Маржа: валовая, операционная, чистая

Создайте три важных серии в виде небольшой серии, и они будут читаться как отчет.

**Разбор и примеры:**
    **formula:**
      
```

## Урок 33. Ликвидность и коэффициенты кредитного плеча

## Урок 34. Временная стоимость денег: NPV и IRR

**Раздел:** Глава 6: Финансовый анализ

**Кратко:**
  NPV и IRR компании numpy-финансовый — и соглашение о нулевом году.

**Объяснение:**
  **is:**
    Деньги, полученные позже, стоят меньше денег, полученных сегодня. Одна функция дисконтирует весь поток к текущему моменту, а другая вычисляет доходность, которую этот поток фактически приносит.

  **use:**
    Он отвечает: «Должны ли мы это финансировать?». Важно понять, где начинаются часы: первая цифра находится в нулевом времени и не учитывается.

  **like:**
    Мне предлагают сто фунтов сейчас или сто фунтов в следующем году. Это не одно и то же предложение, и разница в том, что еще вы могли бы с ним сделать за это время.

**Рабочая ситуация:**
  Сегодня проект стоит 500 тысяч долларов и окупается в течение пяти лет. Стоит ли финансировать это? Доллар в пятом году стоит меньше, чем доллар сегодня, поэтому вы не можете просто сложить притоки. Пакет numpy-финансовый предоставляет вам две функции, к которым стремятся аналитики: НПФ.ЧПС дисконтирует поток к сегодняшним долларам по требуемой ставке, а npf.irr находит доход, который фактически получает проект. Единственное, что нужно знать, это то, где начинаются его часы.

**Разбор и примеры:**
    **formula:**
      
```
импортировать numpy_financial как npf

ср = [-500_000, 150_000, 160_000, 170_000, 180_000, 190_000]
# год 0 год 1 ........... год 5

npv = npf.npv(0.10, cf) # cf[0] имеет значение t=0, НЕ дисконтировано
irr = npf.irr(cf) # скорость, где npv == 0
print(round(npv), round(irr * 100, 1), '%')
```

    **say:**
      Передайте весь список денежных потоков в НПФ.ЧПС с требуемой ставкой — первое значение находится в нулевом времени, без дисконтирования — затем вызовите npf.irr в том же списке, чтобы узнать прибыль, которую зарабатывает проект.

    **lines:**
      - **cf[0] = -500_000:** первоначальная стоимость в нулевом году — включена в список, не дисконтирована
      - **npf.npv(0.10, cf):** скидки каждая последующая перетекает на (1 + ставка)** год и суммирует поток
      - **НПВ > 0:** положительная чистая приведенная стоимость означает, что поток превышает требуемую доходность в 10%.
      - **npf.irr(cf):** ставка, при которой NPV будет равна нулю — собственная прибыль проекта.

**Важно запомнить:**
  Обратите внимание на соглашение о времени: в numpy-финансовый функция ЧПС считает первый элемент списка денежным потоком в момент 0, то есть не дисконтирует его. Поэтому начальные затраты включают прямо в список. В Excel функция NPV считает, что первое значение поступает через один период. Если перепутать эти правила, расчёт будет неверным.

## Урок 35. Бюджет и факт: анализ отклонений

**Раздел:** Глава 6: Финансовый анализ

**Кратко:**
  Объедините план с фактическим, затем пометьте благоприятный или неблагоприятный с помощью np.where.

**Объяснение:**
  **is:**
    Сопоставьте план с реальностью, вычтите, а затем решите, является ли разрыв хорошим или плохим — это зависит от того, идет ли линия «деньги на входе» или «деньги на выходе».

  **use:**
    Превзойти план по продажам — это хорошо; превзойти его по стоимости невозможно. Кодирование этого суждения – вот что предотвращает неправильное прочтение отчета.

  **like:**
    Потратить больше, чем отложили на свадьбу, – плохая новость. Зарабатывать больше, чем вы ожидали, — нет. Та же арифметика, противоположный вердикт.

**Рабочая ситуация:**
  Каждый месяц финансовая команда FP&A сравнивает план с фактом. Разница называется отклонением; важно определить, благоприятно оно или неблагоприятно. Частая ошибка новичков: знак зависит от типа показателя. Превышение плана по выручке — хорошо, а превышение плана по расходам — плохо. Объедините таблицы, вычислите разницу и используйте np.where для оценки, чтобы отчёт нельзя было истолковать неверно.

**Разбор и примеры:**

## Урок 36. Юнит-экономика: маржа вклада и безубыточность

Маржа вклада — это цена минус переменные затраты — то, что каждая единица вносит в постоянные затраты и прибыль. Разделите на него постоянные затраты, и вы получите безубыточность: единицу измерения, при которой бизнес перестает терять деньги.     **formula:**
      
```

**Важно запомнить:**

## Урок 40. Парето: найдите немного жизненно важных

## Урок 41. Корреляция ≠ Причинно-следственная связь

**Кратко:**

**Объяснение:**
  **is:**
    Одно число от минус одного до плюс одного, показывающее, насколько тесно взаимодействуют две вещи. Никогда не говорится, какой из них перемещает другого и делает ли он это.

**Рабочая ситуация:**
  Нужно понять, что влияет на выручку. корр.() — быстрый первый инструмент: он измеряет, насколько согласованно изменяются переменные, от −1 до +1, а точечная диаграмма помогает увидеть связь. Но сильная корреляция — гипотеза, а не доказательство: продажи мороженого связаны с утоплениями, потому что на оба показателя влияет жара. Число помогает выбрать направление исследования, но не доказывает причину.

**Разбор и примеры:**
    **formula:**
      
```
df[['marketing_spend', 'discount_pct', 'revenue']].corr()['revenue']

```

    **say:**
      Используйте корр., чтобы измерить, насколько точно каждый кандидат-водитель отслеживает доход по шкале от минус одного до одного, а затем сравните коэффициенты — при этом помнить, что сильная связь все еще не является доказательством причины.

      - **р около 0:** маленькая ЛИНЕЙНАЯ зависимость — здесь еще может скрываться кривая
      - **Корреляция ≠ Причинно-следственная связь:** скрытая третья переменная может управлять обоими — первое, что следует заподозрить

**Важно запомнить:**
  Корреляция помогает определить направление дальнейшей проверки, но не доказывает причинность. Помните о трёх ловушках: смешивающем факторе, обратной причинности и случайном совпадении. По умолчанию корр.() вычисляет корреляцию Пирсона, которая описывает линейную связь, но сама по себе не доказывает причину.

## Урок 42. Проверка здравомыслия и согласование

**Раздел:** Модуль 7: Набор инструментов для продвинутого аналитика

**Кратко:**
  Привяжите свой номер к надежному элементу управления, прежде чем кто-либо его увидит.

**Объяснение:**
  **is:**
    Поставьте свою фигурку рядом с уже доверенной и проверьте пробел. Ноль означает, что вы проиграли; все остальное означает «остановись и найди это».

  **use:**
    Это последний шаг перед отправкой, который чаще всего пропускают. Если вы этого не сделаете, заинтересованное лицо проведет эту проверку.

  **like:**
    Балансировка кассы при закрытии. Вы не надеетесь, что это совпадет, — вы отказываетесь уйти, пока не поймете, почему это не так.

**Рабочая ситуация:**
  Последний шаг перед отправкой блокнота — это тот, который младшие специалисты пропускают: имеет ли число смысл и связано ли оно с чем-то, кому уже доверяют? При сверке вычисленная цифра помещается рядом с контрольным показателем (закрытие финансового отчета, отчет за прошлый месяц, исходная система) и проверяется разрыв. Ноль означает, что вы проиграли. Все остальное означает остановиться и найти это, потому что заинтересованная сторона это сделает, если вы этого не сделаете.

**Разбор и примеры:**
    **formula:**
      
```
импортировать numpy как np
вычисленный = df.loc[df.fy == 2024, 'сумма'].sum()
control = control_totals.loc[2024, 'итого']
Assert np.isclose(computed, control), f'off by {computed - control:,.0f}'
```

    **say:**
      Подсчитайте общую сумму, извлеките доверенную контрольную цифру и подтвердите, что они близки — так что блокнот остановится на точном разрыве в тот момент, когда число не согласуется.

    **lines:**
      - **вычисленное = … .sum():** число, которое дает ваш анализ
      - **контроль = …:** независимая фигура, которой доверяют — финансовый отдел, последний отчет, источник
      - **np.isclose(computed, control):** сравнивается с допуском с плавающей запятой — не используйте == для сумм с плавающей запятой
      - **утверждать …, ж'выключенный по {разница:,.0ж}':** громкий провал, с напечатанным пробелом — ненулевая разница — это флаг, а не оправдание округления

**Важно запомнить:**
  Число, соответствующее известному элементу управления, заслуживает доверия; тот, который этого не делает, является ошибкой, которую вы не нашли. Используйте np.isclose, Никогда == для сравнения сумм чисел с плавающей запятой — математические вычисления с плавающей запятой оставляют крошечные остатки, которые не проходят точный тест. Когда срабатывает утверждение, обычными подозреваемыми являются вся программа этого модуля: слияние, которое разветвляется (уровень детализации), фильтр, который удаляет строки, или дубликаты. Разница, кратная истине, кричит о зернистости. Правильное размещение утверждения в блокноте означает, что сверка выполняется каждый раз при обновлении данных — об этом нельзя забыть.
