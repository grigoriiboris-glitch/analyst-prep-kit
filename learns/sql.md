Программа курса: 48 уроков по модулям
Модуль 1. Основы реляционных баз данных и выборка данных (Уроки 1–8)

3. Урок 3. Назначение псевдонимов столбцам и таблицам (AS)
Переименование полей в результирующем наборе данных с помощью оператора AS.
4. Урок 4. Фильтрация строк с помощью предложений WHERE
Отбор строк по условиям до начала их группировки или агрегации.

Примеры правильного SQL-синтаксиса и разбор задач
Ниже приведены эталонные примеры запросов, демонстрирующие академический стиль написания SQL-кода и использование корректной терминологии.
Пример 1. Соединение таблиц и агрегация с фильтрацией групп
Задача: Вывести имя клиента (full\_name), количество его заказов и общую сумму покупок, учитывая только подтвержденные заказы со статусом 'paid' для клиентов из Москвы.SELECT
c.full\_name AS customer\_name,
COUNT(o.id) AS total\_orders,
SUM(o.amount) AS total\_spent
FROM customers AS c
INNER JOIN orders AS o
ON c.id = o.customer\_id
WHERE c.city = 'Москва'
AND o.status = 'paid'
GROUP BY c.id, c.full\_name
HAVING COUNT(o.id) >= 2
ORDER BY total\_spent DESC;
Разбор решения:
1. Предложение INNER JOIN соединяет таблицы по совпадению первичного ключа customers.id и внешнего ключа orders.customer\_id.
2. Условие WHERE отбирает исходные строки до расчёта агрегатов.
3. Условие HAVING отсекает сгруппированные данные, оставляя только постоянных клиентов (2 и более заказа).
Пример 2. Анализ динамики продаж с использованием оконных функций
Задача: Рассчитать ежемесячную выручку, нарастающий итог с начала года и процент изменения по сравнению с предыдущим месяцем.l
WITH monthly\_sales AS (
SELECT
DATE\_TRUNC('month', order\_ts) AS sales\_month,
SUM(amount) AS monthly\_revenue
FROM orders
WHERE status = 'paid'
GROUP BY DATE\_TRUNC('month', order\_ts)
)
SELECT
sales\_month,
monthly\_revenue,
SUM(monthly\_revenue) OVER (
ORDER BY sales\_month
) AS running\_total,
LAG(monthly\_revenue, 1) OVER (
ORDER BY sales\_month
) AS prev\_month\_revenue,
ROUND(
(monthly\_revenue - LAG(monthly\_revenue, 1) OVER (ORDER BY sales\_month))
/ LAG(monthly\_revenue, 1) OVER (ORDER BY sales\_month) \* 100, 2
) AS growth\_percentage
FROM monthly\_sales
ORDER BY sales\_month;
\*\*Разбор решения:\*\*
1. Обобщенное табличное выражение (`WITH monthly\_sales`) агрегирует данные по месяцам.
2. Оконная функция `SUM(...) OVER (ORDER BY sales\_month)` рассчитывает нарастающий итог без схлопывания строк.
3. Оконная функция `LAG(..., 1)` извлекает выручку за прошлый месяц для расчета относительного прироста.
